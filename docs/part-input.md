# 漢字パート入力（macOS）

macOS フロントエンドでは、変換する範囲（漢字パート）ごとに入力する。既定では打った文字はすべてパートに入ってライブ変換され、Space でパートを区切って確定する。

SKK 式（`[conversion] skk_style = true`）では、パートを大文字で明示して開き、パートの外は平仮名のまま、打ったそばから確定する。SandS（Space を押したままの Shift）と一緒に使うことを前提にしている。次の例は SKK 式のもの:

```
Honjitu no Kaigi ha  →  本日の会議は
^       ^ ^     ^
|       | |     └ Space でパートを閉じる（ここまでを確定。以降は平仮名）
|       | └ 大文字で次のパートを開く
|       └ Space で「本日」を確定し、「の」は平仮名で確定する
└ 大文字（SandS+h）でパートを開く。パート内はライブ変換される
```

## キー

以下は既定の割り当て。漢字パート入力のキーは、設定ウィンドウの「キー」タブで変えられる（＋ を押してから割り当てたいキーを押す。× で外す。候補を選ぶキーは「記録し直す」を押して8つ順に押す）。`config.toml` では `[keys]` に書く。書き方は Emacs 式で、`C-n`（Ctrl+N）、`S-Tab`（Shift+Tab）、名前のあるキー（`Space` `Return` `Escape` `Tab` `BackSpace` `Delete` `Left` `Right` `Up` `Down` `Home` `End` `PageUp` `PageDown`）、または1文字（`q` `/`）。空白で区切って複数書ける。候補を選ぶキー（`select`）は8文字で、候補窓の2段の並びもこのキーのキーボード上の位置に従う。解釈できない割り当ては設定ウィンドウでは受け付けず、設定ファイルに書かれていたときは既定の割り当てを使う。

### いつでも

| 操作 | キー |
|---|---|
| かなへ戻る（開いているものは確定） | Ctrl+J / かなキー / 右⌘単独タップ |
| 英数（直接入力）へ（開いているものは確定） | 英数キー / 左⌘単独タップ（Karabiner） |
| 英数（直接入力）へ | `l`（かな入力中） |
| 英字のまま変換する（SKK の abbrev） | `/` → 英字 → Space で変換 / Enter でそのまま確定 |
| 入力中のものを捨てる | Ctrl+U |
| 1文字消す | Backspace / Ctrl+H |
| 確定 | Enter / Ctrl+M |

今のモードは、メニューバーのアイコン（あ / A）と、切り替えたときにカーソル近くに出る表示で分かる（Ctrl+J・`l` などは Mimir のバッジ（あ / A）、英数・かなキーや入力メニューからは macOS の表示）。英数モードは入力ソース「英数（Mimir）」として登録されるので、アイコンを連動させるには、システム設定 → キーボード → 入力ソースで「英数（Mimir）」も追加しておく。

入力中（preedit がある間）に、ここにない Ctrl の組み合わせを押しても何も起きない。アプリには渡さない。入力中でなければ、Ctrl+J 以外の Ctrl の組み合わせはすべてそのままアプリに渡る（Ctrl+U で行を消す、など）。

### 平仮名入力（パートの外）

| 操作 | キー |
|---|---|
| パートを開く | 大文字（Shift+文字） |

既定では、小文字でもパートが開く。打った文字は常にライブ変換され、Space でパートを閉じたあとも、次の文字で新しいパートが開く。平仮名のまま確定したいときは、候補窓（Ctrl+N）で平仮名の候補を選ぶ。

`[conversion] skk_style = true`（設定ウィンドウの「一般」の「SKK 式の入力」）にすると SKK 式になり、パートを開くのは大文字だけになる。小文字は平仮名のまま、打ったそばから確定する。以下の説明の「平仮名入力（パートの外）」は、この SKK 式でのことである。

### パート入力中

| 操作 | キー |
|---|---|
| パートを閉じて確定 | Space / Enter / `,` `.` `?` `!`（その記号も続けて入力される） |
| 次のパートを開く（今のパートは確定） | 大文字 |
| 候補窓を開く | Ctrl+N |
| カタカナで確定する | `q`（候補窓を開いているときも） |
| 以前入力した語で補完する | Tab / Ctrl+I（打った読みで始まる、過去に確定した語を候補窓に出す） |
| 候補の出どころを絞って開く | Ctrl+T（学習→辞書→AI→記号の順） |
| パートを取り消す | Ctrl+G / Escape |
| 単語登録 | Ctrl+R → 語を入力 → Enter（Ctrl+G で中止） |
| 変換する範囲を決める（カーソルより左だけ変換） | Ctrl+B / Ctrl+F / Ctrl+A / Ctrl+E（← → Home End も可） |

Google 日本語入力と同じ `z` 入力が使える（zh ← / zj ↓ / zk ↑ / zl → / z. … / z, ‥ / z/ ・ / z- 〜 / z+Space 全角スペース）。`z` の直後の `l`・Space・`,` `.` は、英数への切り替えやパートの終了ではなく、この入力として扱う。

パートの中でカーソルを動かすと、カーソルより左だけを変換の対象にして候補窓を開き、右は右だけで変換し直して後ろに表示する（今日|の天気。左は太い下線、右は細い下線）。Space か候補の選択で左側を確定すると、右側がそのまま次のパートになり、その最初の語が次の対象になって、また候補窓が開く。語は、漢字・カタカナの直後の助詞（は が を に と も へ の や）までで区切り、平仮名から漢字・カタカナに変わる所で次の語が始まる（今日は|いい|天気ですね）。右側が助詞で始まるとき（今日|はいい…）は、その助詞を左側と一緒に確定する。Enter・句読点・大文字など、ほかのキーでパートを閉じたときは両方を確定する（右は表示どおりに）。

```
Kyouhaiitenki   → 今日はいい天気
Ctrl+B ×5       → 今日は|いい天気（左の「きょうは」の候補窓が開く）
j               → 「今日は」を確定。残りの最初の語「いい」の候補窓が開く
Space           → 「いい」を確定し、「天気」の候補窓が開く
```

子音が未確定の間に来た大文字（SandS で Space を離す前に打った `S E` など）は、次のパートを開かずに小文字として続く。

### 候補窓を開いている間

| 操作 | キー |
|---|---|
| 次 / 前の候補 | Ctrl+N / Ctrl+P（Tab / Ctrl+I / Shift+Tab、↓ ↑ も可） |
| 次 / 前のページ | PageDown / PageUp |
| 候補を選んで確定 | `j k f d u i r e`（Ctrl+N / Ctrl+P で選択を動かす前だけ） |
| 選択中の候補で確定 | Space / Enter |
| 候補の出どころを切り替える | Ctrl+T |
| 選んでいる学習候補を履歴から消す | Ctrl+Backspace |
| 候補窓を閉じる | Ctrl+G / Escape / Backspace |
| 単語登録 | Ctrl+R |

候補窓が開いている間に別の文字を打つと、選択中の候補で確定してから入力が続く。Ctrl+N / Ctrl+P で選択を動かしたあとは、選択キーもこの扱いになる（選んだ候補で確定し、その文字から次の入力が始まる）。大文字なら、確定したうえで次のパートを開く。

ライブ変換で漢字になると、どこまで打ったかが見えにくい。読みの見せ方を `[display] reading_display` で選ぶ（設定ウィンドウの「変換中の読み」）。

| 値 | 表示 |
|---|---|
| `"tail"`（既定） | 打った末尾の `tail_chars` 文字（既定 1）を平仮名のまま残す（漢字のかたまりの途中にかかるときは、そのかたまりごと）。子音だけを打った間（規定 + `d`）は変換を戻さない。`tail_delay_ms` ミリ秒（既定 250）手を止めると全体を変換して出す。Backspace で漢字にかからない平仮名を消したとき（規定で → 規定）は漢字のまま出し、漢字の読みを削ったときだけ平仮名で見せる。削除のあとの待ち時間は `tail_delete_delay_ms`（既定 600） |
| `"ruby"` | 入力中の文字列の最後の漢字のかたまりの真上に、その読みを小さく出す。位置は、その漢字の範囲をアプリにたずねて決める（firstRect）。答えないアプリでは、入力中の文字列の先頭として返った位置の上に出る |
| `"inline"` | 最後の漢字のかたまりの読みを後ろに添える（今日はいい天気〈てんき〉）。添えた読みは確定されない |
| `"none"` | 出さない |

候補窓を開いている間は、ふりがなは出さない（候補窓の上端に読みが出る）。

パート入力中は、preedit の下の小さな枠に、打った読みで始まる過去に確定した語（最大3つ）を出す。Tab / Ctrl+I でその候補窓を開く。出さないときは `[display] part_hint = "none"`（設定ウィンドウの「補完候補を表示する」）。
候補窓の上端には読みとページだけを出す。

選択キーは、1番目の候補から `j k f d u i r e` の順（人差し指と中指のホームキー、次にその上のキー。右手が先）で、1ページ8候補。`[display] candidate_layout = "keyboard"`（設定ウィンドウの「候補窓の並び」）にすると、候補をキーボード上のキーの位置どおりに2段で並べる。

```
[e] 快技   [r] 回議      [u] 会ぎ   [i] 海技
[d] 懐疑   [f] 會議      [j] 会議   [k] かいぎ
```


## 学習

学習するのは、モデルの答えとは違うものを自分で選んだときだけである。ライブ変換をそのまま確定したときや、候補窓を開いて最初の候補（開いたときに出ていたもの）のまま確定したときは記録しない。モデルがまた同じ答えを出せるからである。記録するのは、候補窓で別の候補を選んだとき、`q` でカタカナにしたとき、単語登録したときで、直前の文脈（カーソル左の文字列）と一緒に学習キャッシュに記録する。

カーソル左の文字列を IME に渡せないアプリ（iTerm2・ターミナル、その中の Vim など）では、Mimir がそのアプリに入力した直近の文字列（最大40文字）を代わりに文脈として使う。Return・Escape・矢印・Ctrl の組み合わせなど、カーソルが動いたり行が変わったりしうるキーを押すと、この文字列は捨てる。

- **候補窓の並び**: 記録した文脈と末尾が一致するほど、その語が上に来る。
- **ライブ変換**: 直前の句（最後の句読点から後ろ、最大8文字）まで同じ状況で以前確定した語があれば、モデルを呼ばずにその語を出す（「歯が痛いので」＋はいしゃ → 歯医者）。初めての組み合わせ（「車が壊れたので」＋はいしゃ）は、文脈を読むモデルに任せる。
- **1文字の語は単独で学習しない**（`[learning] min_surface_chars = 2`）。「て」「中」のような1文字の語を選んだときは、直前に確定した文（直前のパートと、その後に打った平仮名）とつないで1語として記録する（「入力」＋「中」→ にゅうりょくちゅう → 入力中）。句読点を挟むとつながない。
- 読みにローマ字が残った確定（「s」「でざいn」）は記録しない。
- **カーソルで区切ったパートは、最後まで確定してから1つとして記録する**。区切った左側を選び直しても、その時点では記録しない。右側まで確定したら、全体（きょうのてんき → キョウの天気）を、区切る前の文脈と一緒に学習する。選んだ語が、後に続いた語とセットで残る。選び直さなかったときは、全体を入力の履歴にだけ残す。

補完（Tab / Ctrl+I と補完候補の表示）は学習とは別に、確定した変換をすべて記録した入力の履歴（`history.tsv`）から探す。選ばずにそのまま確定した語も補完には出るが、変換の結果には影響しない。

単語登録した語は学習キャッシュに入るので、その場で効く。`user_dicts/registered.tsv` にも追記され、次の起動からはユーザー辞書としても読まれる。

## 英字のまま変換する（`/`）

何も入力していないときに `/` を押すと、SKK の abbrev と同じく、▽ を出して、続く文字を英字のまま入力する（`l` `q` 大文字もそのまま入る）。Space（または Ctrl+N）で変換し、Enter で打ったとおりに確定する。Ctrl+G / Escape で取り消す。変換候補は、英字の読みを持つ辞書の語と、大文字・全角の形である。辞書の語は SKK 辞書から取り込む（次の節の `--abbrev`）。`・` は `z/` で入力する。

## SKK 辞書の取り込み

```sh
scripts/skk2mozc.py ~/Library/Application\ Support/AquaSKK/skk-jisyo.utf8 \
    > ~/Library/Application\ Support/com.mimir.mimir-im/user_dicts/skk-user.tsv
```

英字の読みの項目（`github /GitHub/`）は `--abbrev` で取り込む。かな入力の読みとは重ならないので、SKK-JISYO.L のような大きな辞書から取り込んでよい。

```sh
scripts/skk2mozc.py --abbrev ~/Library/Application\ Support/AquaSKK/SKK-JISYO.L \
    > ~/Library/Application\ Support/com.mimir.mimir-im/user_dicts/skk-abbrev.tsv
```

取り込めるのは送りなしエントリだけである。ユーザー辞書の候補はモデルの候補より上に並ぶので、SKK-JISYO.L のような大きな一般辞書は入れない方がよい。

## 設定ウィンドウ

入力メニュー（メニューバーの「あ」）の「Mimir の設定…」で開く。設定の変更はその場で `config.toml` に保存され、エンジンを再起動して反映される。保存時に `config.toml` を読み直して書き出すので、ファイル中のコメントは消える（値は残る）。

| タブ | できること |
|---|---|
| キー | 漢字パート入力のキーの割り当て（`[keys]`） |
| 一般 | 「操作」SKK 式の入力（`[conversion] skk_style`）。「表示」変換中の読み（`[display] reading_display` `tail_delay_ms` `tail_delete_delay_ms`）、候補窓を出すタイミング（`[display] candidate_window`）、候補窓の並び（`[display] candidate_layout`）、補完候補の表示（`[display] part_hint`）。「変換」予測候補（`[conversion] predictive`）、学習の有無（`[learning] enabled`）、日付・時刻の変換（`[date] enabled`） |
| モデル | メイン / 軽量モデルの選択。組み合わせに名前を付けて保存・切替・削除（`[profiles.<名前>]`）。「計測する」で全モデルの精度・1回あたりの時間・読込時間をこの Mac で測る |
| 辞書 | `user_dicts/` の TSV 辞書の一覧・検索・追加（`registered.tsv` へ）・削除。バイナリ辞書は名前だけ表示 |
| 学習 | 学習履歴の一覧・検索・削除・すべてリセット |

計測の対象は、学習履歴に10件以上の変換があれば直近50件（読みと、そのとき選んだ語と文脈）、なければ内蔵の例文20件である。学習履歴を使う場合は、そのとき使っていたモデルの出力を選んだ結果が多く含まれるので、そのモデルに有利に出る。計測は別プロセスで走るので、その間も入力は止まらない。
