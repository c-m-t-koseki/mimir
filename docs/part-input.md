# 漢字パート入力（macOS）

macOS フロントエンドでは、変換する範囲（漢字パート）を自分で明示して入力する。範囲の外は平仮名のまま、打ったそばから確定する。SandS（Space を押したままの Shift）と一緒に使うことを前提にしている。

```
Honjitu no Kaigi ha  →  本日の会議は
^       ^ ^     ^
|       | |     └ Space でパートを閉じる（ここまでを確定。以降は平仮名）
|       | └ 大文字で次のパートを開く
|       └ Space で「本日」を確定し、「の」は平仮名で確定する
└ 大文字（SandS+h）でパートを開く。パート内はライブ変換される
```

## キー

| 操作 | キー |
|---|---|
| パートを開く | 大文字（Shift+文字）/ `q` |
| パートを閉じて確定 | Space / Enter / `,` `.`（句読点も続けて入力される） |
| 候補窓を開く・次候補 | Ctrl+N |
| 前候補 | Ctrl+P |
| 候補を選んで確定 | `a s d f j k l` |
| 候補窓を閉じる / パートを取り消す | Ctrl+G |
| 単語登録 | パート内で Ctrl+R → 語を入力 → Enter（Ctrl+G で中止） |
| 英数（直接入力）へ | `l` |
| かなへ戻る | Ctrl+J / かなキー |

パート内の変換結果が読みと違うときは、preedit の下に読み（平仮名）を小さく表示する。候補窓の下端には読みとページだけを出す。

候補窓が開いている間に別の文字を打つと、選択中の候補で確定してから入力が続く。大文字なら、確定したうえで次のパートを開く。

## 学習

パートの確定内容は、直前の文脈（カーソル左の文字列）と一緒に学習キャッシュに記録される。同じ読みを次に入力したとき、記録した文脈と末尾が一致するほど、その語が優先される。読み全体に学習がある場合、ライブ変換はモデルを呼ばずに学習結果を表示する。

単語登録した語は学習キャッシュに入るので、その場で効く。`user_dicts/registered.tsv` にも追記され、次の起動からはユーザー辞書としても読まれる。

## SKK 辞書の取り込み

```sh
scripts/skk2mozc.py ~/Library/Application\ Support/AquaSKK/skk-jisyo.utf8 \
    > ~/Library/Application\ Support/com.karukan.karukan-im/user_dicts/skk-user.tsv
```

取り込めるのは送りなしエントリだけである。ユーザー辞書の候補はモデルの候補より上に並ぶので、SKK-JISYO.L のような大きな一般辞書は入れない方がよい。
